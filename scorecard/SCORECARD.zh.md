# 分配方案分离自评表 v1.1

用四个问题检验：一个分配方案宣布的分红，能不能长期兑现。

## 这张表做什么

任何声称把 AI 或自动化生产的收益、资源收益分给人的方案，都可以用这张表自评，也可以由第三方来评。企业承诺、公共或主权基金、全民收入试点、平台分成、链上协议都适用。

它只检验一件事：方案的结构能不能让它宣布的分红长期兑现。依据是两篇论文。《把捕获与分配分开》的命题 4：对机器自主产出的分红为正，当且仅当三条同时成立——规则事前定死（Q1），受约束的人看得见（Q2），定规则的人不拿没分掉的部分（Q3）。《把规则卡在瓶颈上》的命题 1：一条规则实际能收到的，不超过绕开它的成本（Q4）。

它不评价分红比例是否合理、方案的商业前景，也不评价任何代币或资产的价格。四问全过是分红能够兑现的必要条件，不是充分条件。

## 填写规则

1. 每个回答都附证据：链接、合约地址、法条、章程条款或审计报告。
2. 没有证据的回答记为“无法核实”，按未通过计。外人无法核实，本身就不满足 Q2。
3. 注明填写人是方案自评还是第三方评估。任何人都可以就同一方案提交另一份评估，几份评估并列公开。
4. 注明评估日期和方案版本。方案改动后重新评估。
5. 可以写计划中的改进，但判定只看评估当日已经生效的状态。

## 二、Q1 预先承诺

产出实现之后，有没有哪个会从改分法中获益的一方，能修改或豁免规则？

| 编号 | 问题 | 回答 | 证据 |
|---|---|---|---|
| 1.1 | 列出所有能修改分配规则的主体：管理员密钥、可升级代理、多签、治理投票、董事会、立法机构等 | | |
| 1.2 | 修改从提出到生效有多长的公告期？与捕获方的投资周期相比如何？ | | |
| 1.3 | 修改能否作用于已经实现、尚未发放的产出？ | | |
| 1.4 | 有没有暂停、紧急或豁免权限？谁持有，什么条件下可以触发？ | | |
| 1.5 | 规则被违反时，接收方有什么可执行的救济（诉讼、链上强制执行、退出）？ | | |

判定：
- **通过**：没有任何主体能在产出实现后单方面修改或豁免规则（1.1、1.3、1.4），修改须经公告期才对此后的产出生效（1.2）。
- **部分**：修改须经公告期、不溯及既往，但存在可单方面触发的暂停权。
- **未通过**：有任何主体能在产出实现后单方面修改或豁免规则。

## 三、Q2 可观察

受规则约束的人，能否在行动之前核实规则，并在事后核实发放？

| 编号 | 问题 | 回答 | 证据 |
|---|---|---|---|
| 2.1 | 规则全文是否公开，放在唯一的权威位置，并有版本号？ | | |
| 2.2 | 接收方能否事后核实每一笔发放（链上数据、审计报告、公开名册）？ | | |
| 2.3 | 被分配的底数（总产出或总收入）是否公开，而不只是发放额？ | | |
| 2.4 | 规则的修改历史是否公开、可追溯？ | | |
| 2.5 | 核实是否需要许可、付费，或普通人拿不到的权限？ | | |

判定：
- **通过**：2.1 至 2.4 都是“是”，2.5 是“否”。
- **部分**：规则和发放可查，但底数不公开，因而无法核对规则是否按比例执行。
- **未通过**：规则或发放无法查证。

## 四、Q3 独立

设定规则、能修订规则或控制收取环节的人，是否保留规则没有分掉的部分？

| 编号 | 问题 | 回答 | 证据 |
|---|---|---|---|
| 3.1 | 谁设定规则，谁能修订？（与 1.1 对照） | | |
| 3.2 | 这些主体是否以任何形式取得未分配的剩余：股权、利润、国库、手续费、税收、所持资产升值？ | | |
| 3.3 | 修订权按什么分配：按人、按持有量、按出资，还是指定？ | | |
| 3.4 | 捕获方及其关联方合计持有多少修订权（投票权、席位）？ | | |
| 3.5 | 定规则的人如何产生，任期多长，能否被罢免？ | | |
| 3.6 | 谁拥有或控制规则的收取环节（见 4.1）？它在这个环节上是否自己收费，是否取得规则没有分掉的部分？ | | |

判定：
- **通过**：有修订权的主体和控制收取环节的主体都不取得剩余；或者它们在剩余中的利益相对其权力可以忽略，并已公开披露。
- **部分**：修订权分散，取得剩余的主体只持有少数修订权，且不控制收取环节。
- **未通过**：能修订规则的主体同时是剩余的取得者；或者取得剩余的主体控制多数修订权；或者控制收取环节的主体取得剩余，并能决定在该环节收多少。

第一篇论文第 3.4 节说明了原因：定规则的人在剩余中的利益越大，行为就越像捕获方。第二篇论文的命题 5 把同一个问题放到收取环节上：瓶颈有主人时，主人已经在收这笔钱，在它之上再加一层征收，最多只能收到主人原有收入的一半。

## 五、Q4 可执行

把一单位产出绕开规则要花多少成本？规则要的，是不是比这少？

| 编号 | 问题 | 回答 | 证据 |
|---|---|---|---|
| 4.1 | 规则卡在哪个环节：产出端（收入、手续费、销售额）、投入端（算力、能源、牌照、区块空间），还是两处都卡？ | | |
| 4.2 | 相关产出中，多大比例必须经过这个环节？ | | |
| 4.3 | 有哪些办法能让产出绕开这个环节（换平台、换合约、换链、换辖区、换主体、场外结算）？每单位大约要花多少成本？ | | |
| 4.4 | 规则在这个环节每单位收多少？是否低于 4.3 的绕行成本？ | | |
| 4.5 | 规则由机制本身执行（不付就无法成交），还是靠可以选择不执行的中间方（交易平台、托管方、代理机构）？ | | |
| 4.6 | 过去一个周期里，实际收到的占按规则应收的多少？ | | |

判定：
- **通过**：收取环节明确（4.1）；规则所收低于有据可查的绕行成本，或在机制内无法绕开（4.3 至 4.5）；实收与应收基本一致（4.6）。
- **部分**：一部分产出能以低于规则所收的成本绕开，但多数仍经过规则；或者绕行成本没有估计，但实收接近应收。
- **未通过**：绕行成本低于规则所收，且产出已经转移；或者规则的执行取决于可以随时停止执行的中间方。

第二篇论文的命题 1 说明了原因：规则定得高于绕行成本，收到的是零。命题 3 补充：捕获方之间有差别时，产出端和投入端两处都卡，比只卡一处收得多。

## 七、汇总

| 问题 | 判定（通过 / 部分 / 未通过 / 无法核实） | 主要依据 |
|---|---|---|
| Q1 预先承诺 | | |
| Q2 可观察 | | |
| Q3 独立 | | |
| Q4 可执行 | | |

Q1 至 Q3 全部通过，称为“分离”。四问全部通过，称为“分离且可执行”。否则写出卡住的那一问。结论可以用这个句式：

> 按评估日的状态，本方案在 Q__ 上未通过，原因是 ______。在这一点解决之前，它宣布的分红比例不能被视为一项承诺。

## 八、三个示例

以下根据公开信息填写，只用于演示表格的用法，不构成对任何方案的推荐。

**示例一：以太坊 EIP-1559 的基础费销毁**

| 问题 | 判定 | 依据 |
|---|---|---|
| Q1 | 通过 | 基础费由公开公式按此前区块的拥挤程度确定，并被销毁。出块者不能修改公式，改动需要全网硬分叉。 |
| Q2 | 通过 | 规则公开；每个区块的基础费和销毁量都可以在链上查证。 |
| Q3 | 通过（附注） | 捕获方（出块者）控制打包这个环节，但不取得基础费。销毁使全体 ETH 持有者受益，参与升级决策的人也可能持有 ETH。 |
| Q4 | 通过（附注） | 基础费是区块有效性规则的一部分，不付就无法被打包，用户与出块者私下结算也替代不了它。要绕开，只能把活动移到别的链或二层网络。 |
| 补充 B | — | 销毁按持有量惠及持币人，不是按人的存在分红。 |

**示例二：阿拉斯加永久基金分红**

| 问题 | 判定 | 依据 |
|---|---|---|
| Q1 | 未通过 | 法律中有计算公式，但金额每年在预算中重定。2017 年州最高法院在 Wielechowski 案中裁定，分红受普通拨款与否决程序约束。 |
| Q2 | 通过 | 法定公式和每年实发金额都公开。 |
| Q3 | 未通过 | 决定金额的议会同时支配没有分掉的部分。 |
| Q4 | 通过 | 州对矿产收取权利金，资源搬不走；州宪法规定其中至少 25% 进入永久基金。问题出在 Q1 和 Q3，不在收取环节。 |
| 结果 | — | 2025 年按法定公式约为每人 3,900 美元，实发 1,000 美元。 |

**示例三：NFT 创作者版税（只看 Q4）**

| 问题 | 判定 | 依据 |
|---|---|---|
| Q4 | 未通过 | 版税由交易平台代为执行，不是成交的必要条件。平台相互竞争时，Blur 把最低版税定在 0.5%，而创作者设定的通常是 5% 至 10%；OpenSea 于 2023 年 8 月宣布不再强制执行。 |
| 结果 | — | 每周版税收入从 2022 年 4 月高点的约 28,000 ETH，降到 2023 年 6 月的约 2,000 ETH；同期市场本身也在收缩。 |

State (2017)](https://law.justia.com/cases/alaska/supreme-court/2017/s-16558.html)；[Alaska Public Media, 2025-05-02](https://alaskapublic.org/news/politics/2025-05-02/alaska-senate-committee-drops-proposed-2025-pfd-to-1-000-per-recipient-an-inflation-adjusted-low)；[Alaska Permanent Fund Corporation, The Fund](https://apfc.org/the-fund/)；[The Art Newspaper, 2023-08-23](https://www.theartnewspaper.com/2023/08/23/opensea-nft-marketplace-ending-resale-royalties-policy)；[Cointelegraph, OpenSea 停用版税执行工具](https://cointelegraph.com/news/opensea-disable-on-chain-royalty-enforcement-tool)。
